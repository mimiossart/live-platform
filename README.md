# LiveWave

MVP d'une plateforme de live vidéo verticale.

Écrans : Accueil, Connexion, fil vertical de lives, salle de live + chat, création de live, profil utilisateur.

Démarrage : npm install puis npm run dev.

Prochaine étape : brancher Supabase pour Auth, profils, lives et chat Realtime, puis un fournisseur de streaming (LiveKit, Mux, Cloudflare Stream, etc.) pour le flux vidéo réel.
